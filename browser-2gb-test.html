4a. Subtitle Extraction — MKV Fast Path (no FFmpeg)

Pure-JS Matroska parser. Reads only EBML headers and Cluster bodies, skips video/audio block payloads via byte-offset arithmetic. No FFmpeg WASM, no full decode pass — typically 5-15× faster than the FFmpeg path on the same MKV. Output is byte-comparable to ffmpeg -map 0:N -c:s copy for SubRip streams.

4. Subtitle Extraction — FFmpeg path (all tracks → ZIP)

Calls VideoMetadataExtractor.extractAllSubtitles end-to-end: enumerates subtitle streams, extracts each one via FFmpeg WASM, packages them into a ZIP, and triggers download. Honors the 2GB Blob browser limit via the lib's chunked-streaming path. On a 14GB MKV this takes several minutes — keep the tab open.
